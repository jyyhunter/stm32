# AS5600 磁编码器速度测量（STM32F103VET6 + I2C OLED）

读取 AS5600 磁编码器的绝对角度，实时计算**转速（RPM）、角速度（°/s）**，

在 0.96 寸 I2C OLED（SSD1306）上显示，并通过串口周期发送。



* 芯片：STM32F103VET6，标准外设库（StdPeriph），主频 72MHz

* 编码器：AS5600，12 位绝对角度（0\~4095），软件 I2C，地址 0x36

* 显示屏：0.96 寸 OLED 128×64，SSD1306，软件 I2C，地址 0x78

* 串口：USART3，115200, 8N1，printf 重定向（MicroLib）

* 全部为整数定点运算，不依赖浮点 printf



***

## 一、硬件接线

AS5600 和 OLED 是**两条互相独立的软件 I2C 总线**（不共用引脚），

VCC 一律接 **3.3V**，禁止接 5V。



| 器件         | 器件引脚    | 接到 STM32                | 说明         |
| ---------- | ------- | ----------------------- | ---------- |
| AS5600 编码器 | VCC     | 3.3V                    | 电源         |
| AS5600 编码器 | GND     | GND                     | 地          |
| AS5600 编码器 | SCL     | **PB6**                 | 软件 I2C1 时钟 |
| AS5600 编码器 | SDA     | **PB7**                 | 软件 I2C1 数据 |
| OLED 显示屏   | VCC     | 3.3V                    | 电源         |
| OLED 显示屏   | GND     | GND                     | 地          |
| OLED 显示屏   | SCL     | **PB8**                 | 软件 I2C2 时钟 |
| OLED 显示屏   | SDA     | **PB9**                 | 软件 I2C2 数据 |
| USB 转 TTL  | RXD     | **PB10**（USART3\_TX）    | 串口接收       |
| USB 转 TTL  | TXD     | **PB11**（USART3\_RX，可选） | 串口发送       |
| USB 转 TTL  | GND     | GND                     | 必须共地       |
| USB 转 TTL  | 3.3V/5V | 不接                      | 开发板独立供电    |

> 模块的 SCL/SDA 一般自带上拉电阻，无需外接；若没有可在 SCL/SDA 各加一个 4.7kΩ 上拉到 3.3V。

### 磁铁安装（AS5600）



* 使用**径向充磁**的圆形磁铁（常见 Ø6mm），不能用轴向充磁磁铁。

* 磁铁圆心对准芯片中心，置于芯片正上方，间距约 **1\~3mm**。

* 磁铁随转轴旋转，AS5600 芯片固定不动。

* 磁场异常时 OLED 第 1 行右侧显示 `HI`（过强）/ `LO`（过弱），正常显示 `OK`，未检测到磁铁显示 `NO`。



***

## 二、OLED 显示内容

屏幕 128×64，4 行 × 16 列（8×16 字符）：



```
AS5600  SPEED OK      <- 第1行：标题 + 磁铁状态(OK/NO/HI/LO)
RPM +060.05           <- 第2行：转速（转/分），带符号，正转+反转-
ANG +180.25           <- 第3行：当前绝对角度（度）
D/s +0360.3           <- 第4行：角速度（度/秒），带符号
```



***

## 三、串口数据格式



* 参数：**115200, 8N1**，每 **100ms** 发送一行（10Hz）。

* 串口助手请把接收编码设为 **UTF-8 / 英文**（输出为纯英文，避免乱码）。

示例：



```
RPM=+060.05  ANG=180.25  DPS=+0360.3  REV=+1
RPM=+060.05  ANG=183.79  DPS=+0360.3  REV=+1
```



| 字段  | 含义             | 定标                 |
| --- | -------------- | ------------------ |
| RPM | 转速（转 / 分），带符号  | 已按 0.01rpm 显示      |
| ANG | 绝对角度（度）        | 0\~359.99，0.01° 精度 |
| DPS | 角速度（度 / 秒），带符号 | 0.1°/s 精度          |
| REV | 上电后累计圈数，带符号    | 整数圈，可用于判断多圈位置 / 方向 |



***

## 四、测速原理（M 法 + 滑动窗口）

代码在 `Hardware/Speed.c`：



1. 每 **50ms**（`SPEED_SAMPLE_MS`）读一次 AS5600 原始角度；

2. 与上一次角度做差得到带符号增量，并处理 0/4095 回绕：

* 增量 > 2047 视为反向过零点，减 4096；

* 增量 < -2047 视为正向过零点，加 4096；

1. 用最近 **4** 个增量（共 **200ms**，`SPEED_WINDOW_N`）做滑动求和，降低低速量化跳动；

2. 整数定点换算：

* `RPM×100 = 窗口增量 × 30000 / 4096`

* `角速度(°/s)×10 = 窗口增量 × 18000 / 4096`

* `角度(°)×100 = raw × 36000 / 4096`

### 量程与分辨率



* 量程约 **±600 rpm**：受 “单个采样周期（50ms）内转过不超过半圈” 限制，否则过零点方向会判反。

* 低速分辨率约 0.07 rpm（200ms 窗口内最少 1 个刻度）。

* 速度刷新延迟约 200ms（一个滑动窗口长度）。

### 调参（`Hardware/Speed.h`）



* 需要测**更高转速**：减小 `SPEED_SAMPLE_MS`（如 20ms），或减小 `SPEED_WINDOW_N`。

* 需要测**更低、更稳的转速**：增大 `SPEED_WINDOW_N`（如 8），代价是响应变慢。

* 改动后务必同步核对 `Speed.c` 中的换算系数（RPM 用 60、DPS 用 360，窗口时长 = 采样周期 × 窗口数）。

## 五、代码结构



| 文件                                 | 作用                                       |
| ---------------------------------- | ---------------------------------------- |
| `Hardware/AS5600.c/.h`             | AS5600 软件 I2C 驱动（PB6/PB7），读原始角度 / 状态     |
| `Hardware/OLED.c/.h`、`OLED_Font.h` | SSD1306 OLED 软件 I2C 驱动（PB8/PB9）及 8×16 字库 |
| `Hardware/Speed.c/.h`              | 速度测量：周期采样、回绕处理、滑动窗口、RPM / 角速度换算          |
| `Hardware/Serial.c/.h`             | USART3（PB10/PB11）初始化与 printf 重定向         |
| `Hardware/Tick.c/.h`               | TIM2 产生 1ms 周期中断，提供 `g_tick_ms` 毫秒时基     |
| `System/Delay.c/.h`                | SysTick 微秒 / 毫秒延时                        |
| `User/main.c`                      | 主程序：按毫秒节拍采样、刷新 OLED、串口上报                 |

> 软件 I2C 时序在主循环执行（不在中断里），TIM2 中断仅用于毫秒计数，避免 I2C 阻塞中断。

## 六、在 Keil 中编译下载



1. 用 Keil MDK5 打开 `Project.uvprojx`（目标 Target 1，器件 STM32F103VE，已配置标准外设库与 MicroLib）。

2. 点击 **Build（F7）** 编译，工程已验证 **0 Error / 0 Warning**，输出 `Objects\EncoderSpeed.hex`。

3. 用 ST-Link / J-Link 或串口 ISP 下载 HEX 到开发板。

4. 上电后打开串口助手（115200, 8N1），转动磁铁即可看到转速变化，OLED 同步刷新。

## 七、常见问题



* **OLED 不亮 / 花屏**：检查 PB8/PB9 是否接反、VCC/GND 是否正确；部分模块 I2C 地址为 0x7A（在 `OLED.c` 中把 0x78 改为 0x7A 试试）。

* **串口无输出**：确认接的是 USART3 的 PB10 (TX)→USB 转 TTL RXD，且两边共地；串口助手波特率 115200。

* **角度一直为 0、OLED 显示 NO**：磁铁未装或距离 / 方向不对，AS5600 未检测到磁铁。

* **速度在快速转动时方向错误**：超过量程（50ms 内转过半圈），请按第四节调小采样周期。

* **OLED 显示上下 / 左右颠倒**：在 `OLED.c` 的 `OLED_Init` 中调整 `0xA1/0xA0`、`0xC8/0xC0` 两条命令。
